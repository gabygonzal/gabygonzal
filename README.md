## Projects 📂

**[Frantattz](https://frantattz.com/) — Tattoo Artist Booking Site** 

Full production booking site built as a gift for a friend, a professional tattoo artist. Built with Next.js, TypeScript, and Tailwind, using Supabase for the backend, Google Calendar OAuth for scheduling, and Resend for email notifications.

**[Okàn](https://okan-journal.vercel.app/)— Wellness Journaling App**

Personal wellness journaling app deployed live at okan-journal.vercel.app, featuring a realistic book-flip interface with four distinct journal types. Built with React, Vite, Tailwind, Supabase, react-pageflip, and Recharts. Started as a course assignment, with plans to ship it to real users.

**ForecastFlex — Cost & Viability Analysis Platform**

Company-sponsored senior capstone, built solo as front-end lead. A cost and viability analysis platform with dynamic drill-down, cost entry, and scenario-based projections, built in React and TypeScript. Features a custom design system with light/dark theming and a D3-powered interactive map, delivered from wireframe to stakeholder sign-off and a live panel demo.

**HeraHealth — Group Fitness Platform**

Group fitness web app built collaboratively with a six-person team. Owned the entire coach portal — dashboard, client management, workout plan builder, meal plans, scheduling, and chat — built with Next.js, TypeScript, and a custom CSS system, with a Flask backend integration planned.

**DevConnect — Professional Networking Platform**

Front-end developer on a networking website for computer science students, with an emphasis on usability and user interface. Developed UI components and contributed to a resume builder tool that converts user information into formatted documents within the website.
